# 팝업 창 (빌리기 · 반납 창)

입력이 필요한 행동에만 써요. 단순 안내는 하단 토스트로 충분해요.

## 구성 (위에서부터)
1. 제목: 행동 이름 그대로 (빌리기 · 반납하기)
2. 대상 차량: 「차종 · 번호판」 굵게 + 보조 정보(위치 또는 빌린 사람 · 기간) label1 · neutral.secondary
3. 거절 안내: DB가 거절하면 맨 위에 안내 메시지(negative) — 문구는 `문구.md` 오류 문구
4. 입력창들 (간격 16px)
5. 아래 버튼: 왼쪽 「취소」 · 오른쪽 주요 버튼(행동 이름)

## 규칙
- 크기는 popup · medium 을 써요.
- 저장 중에는 바깥을 눌러도 닫히지 않아요.
- 마지막 입력창에서 Enter 를 누르면 저장해요.
- 저장에 성공하면 창을 닫고 하단 토스트로 알려요.
- 다른 사람이 먼저 바꿔서 거절됐으면 목록을 새로 불러와요.
