# 상태 배지

차량 상태 하나를 짧은 글자로 보여 줘요. 색과 이름은 `상태표현.md` 를 따라요.

## 모양
| 상태 | 배지 종류 | 색 |
|---|---|---|
| 사용가능 | 강조 배지 (accent) | positive.primary |
| 사용중 | 강조 배지 (accent) | brand.primary |
| 반납 지연 | 강조 배지 (accent) | negative.strong |
| 정비중 | 기본 배지 (neutral) | 회색 |

## 규칙
- 크기는 small 하나만 써요.
- 배지는 차종 · 번호판 **바로 오른쪽**에 둬요.
- 배지 글자는 화면 이름(사용가능 · 사용중 · 반납 지연 · 정비중)만 써요. 「대기」 같은 DB 이름은 쓰지 않아요.
- 배지를 버튼처럼 누르게 만들지 않아요.
