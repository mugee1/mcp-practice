# 입력창

## 구성
- 이름표(label) + 필수 표시 · 입력칸 · 아래 안내 한 줄
- 칸 너비는 창 가득(100%)

## 규칙
- 모든 칸이 필수면 모든 이름표에 필수 표시를 해요.
- placeholder 에는 **예시**를 써요: 「예: 직원B」 「예: 총무팀」 「예: 고객사 미팅」
- 오류는 **저장 버튼을 누른 뒤에** 보여 줘요 (처음부터 빨갛게 하지 않기).
- 오류가 있으면 칸 테두리를 negative 로 바꾸고 바로 아래에 이유를 써요 — 문구는 `문구.md`.
- 오류가 없을 때 아래 안내 줄에 도움말을 쓸 수 있어요: 「반납 시간은 저장하는 순간으로 자동 기록돼요.」
- 단위가 있으면 칸 오른쪽 끝에 붙여요: 주행거리 「km」
- 숫자만 받는 칸은 휴대폰에서 숫자 키패드가 뜨게 해요.
- 날짜 · 시간 칸의 기본값은 「지금부터 2시간 뒤, 30분 단위」예요.

## 배차판 입력칸
| 창 | 칸 |
|---|---|
| 빌리기 | 사용자 · 부서 · 반납 예정 · 목적 |
| 반납 | 주행거리(km) |
