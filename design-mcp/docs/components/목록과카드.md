# 목록과 카드 · 검색 · 필터

## 요약 카드 (요약 바)
- 4칸(사용가능 · 사용중 · 반납 지연 · 정비중)을 한 줄에, 좁으면 줄바꿈
- 배경 background.neutral.secondary · 모서리 radius.card(12px) · 안쪽 12px 16px
- 위: 칸 이름 label2 · neutral.secondary / 아래: 숫자 title3 굵게 · 상태 색

## 사용중 카드 (지금 사용중 목록)
- 테두리 line.neutral.primary · 반납 지연이면 line.negative.primary
- 배경 background.neutral.primary · 모서리 12px · 안쪽 14px 16px · 카드 사이 8px
- 1줄: 번호판 굵게 · 차종 · 상태 배지
- 2줄: 사용자 · 부서 · 목적
- 3줄: 「○○까지」 (지연이면 굵게 + 빨강 + 「반납 예정 시간이 지났어요」)
- 오른쪽: 「반납하기」 보조 버튼

## 차량 목록 줄 (전체 차량)
- 카드 없이 줄 아래 구분선 line.neutral.secondary
- 1줄: 차종 굵게 + 상태 배지 / 2줄: 번호판 · 위치 · 연료 · 인승
- 오른쪽 버튼: 사용가능이면 「빌리기」, 사용중 · 지연이면 「반납하기」, 정비중이면 없음

## 검색 · 필터
- 검색창 placeholder: 「차량번호 · 차종 · 위치 검색」 — 띄어쓰기 · 대소문자 무시
- 필터(세그먼트): 전체 · 사용가능 · 사용중 · 정비중 (사용중에 반납 지연 포함)
- 검색창과 필터는 한 줄, 좁으면 줄바꿈
