# 상태 표현 규칙

차량 한 대는 언제나 아래 네 상태 중 하나예요. DB 이름을 화면에 그대로 쓰지 않고 **화면 이름**으로 바꿔 보여 줘요.

| DB 상태 | 화면 이름 | 색 토큰 | 표현 |
|---|---|---|---|
| 대기 | 사용가능 | positive.primary | 강조 배지 (초록) · 「빌리기」 버튼 보임 |
| 사용 중 | 사용중 | brand.primary | 강조 배지 (파랑) · 「반납하기」 버튼 보임 |
| 반납 지연 | 반납 지연 | negative.strong | 강조 배지 (빨강) · 카드 테두리 line.negative.primary · 굵은 경고 문장 |
| 정비중 | 정비중 | (회색 기본 배지) | 회색 배지 · 버튼 없음 |

## 반납 지연
- 반납 예정 시간이 지났는데 아직 반납하지 않은 차예요.
- 카드 테두리를 빨강(line.negative.primary)으로 바꾸고, 시간 줄을 굵게 + negative.strong 으로 써요.
- 문장: 「11/17(월) 16:30까지 · 반납 예정 시간이 지났어요」
- 「사용중」 목록에서 반납 예정이 빠른 순으로 정렬해요 (지연된 차가 맨 위).

## 정비중
- 빌리기 · 반납 버튼을 모두 숨겨요. 회색 배지만 보여요.
- 정비중인 차를 빌리려 하면 DB가 거절하고 「정비중인 차라서 빌릴 수 없어요.」를 보여 줘요.

## 요약 바 색
| 칸 | 숫자 색 |
|---|---|
| 사용가능 | positive.primary |
| 사용중 | brand.primary (반납 지연 포함 개수) |
| 반납 지연 | negative.strong |
| 정비중 | neutral.tertiary |

## 실시간 연결 표시 (요약 바 오른쪽 위)
| 상태 | 문장 | 색 |
|---|---|---|
| 연결 중 | 실시간 연결 중… | neutral.tertiary |
| 연결됨 | ● 실시간 반영 중 | positive.primary |
| 끊김 | ○ 실시간 끊김 · 1분마다 갱신 | neutral.tertiary |

## 규칙
- 색만으로 상태를 구분하지 않아요. 배지에는 언제나 **글자**(사용가능 · 사용중 …)가 함께 있어요.
- 같은 상태는 모든 화면에서 같은 색 · 같은 이름을 써요.
