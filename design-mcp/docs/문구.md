# 문구 규칙

## 말투
- 「~해요」체로 써요. 「~합니다」 · 「~하십시오」는 쓰지 않아요.
- 사과보다 **해결 방법**을 먼저 말해요.
  - ⭕ 인터넷 연결을 확인하고 다시 시도해 주세요.
  - ❌ 죄송합니다. 오류가 발생했습니다.
- 개발 용어(에러 코드 · duplicate key · RPC)는 화면에 보여 주지 않아요.

## 용어
| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 빌리기 | 대여 · 배차 신청 · 렌트 |
| 반납하기 | 회수 · 반환 |
| 사용가능 | 대기 · 가용 |
| 사용중 | 운행중 · 대여중 |
| 반납 예정 | 반납 기한 · 마감 |
| 주행거리 | 운행거리 · 마일리지 |

- 단위는 숫자 뒤에 붙여 써요: 3대 · 42km · 7인승
- 시간은 한국 시간 「11/17(월) 16:30」 형식이에요.

## 오류 문구 (DB가 거절했을 때)
| 상황 | 문구 |
|---|---|
| 다른 사람이 먼저 빌림 | 이미 다른 분이 사용 중인 차예요. 목록을 새로 불러왔으니 다른 차를 골라 주세요. |
| 정비중인 차 | 정비중인 차라서 빌릴 수 없어요. |
| 반납 예정이 과거 | 반납 예정 시간은 지금보다 뒤로 정해 주세요. |
| 빈 칸 | 사용자 · 부서 · 반납 예정 · 목적을 모두 채워 주세요. |
| 주행거리 잘못 | 주행거리는 1 이상의 숫자(km)로 적어 주세요. |
| 이미 반납됨 | 이미 반납된 차예요. 목록을 새로 불러왔어요. |
| 없는 차 | 등록되지 않은 차량이에요. |
| 인터넷 끊김 | 인터넷 연결을 확인하고 다시 시도해 주세요. |
| 그 밖의 오류 | 저장하지 못했어요. 잠시 후 다시 시도해 주세요. |

## 입력창 아래 안내 (칸을 비웠을 때)
- 사용자 이름을 적어 주세요. / 부서를 적어 주세요. / 목적을 적어 주세요.
- 반납 예정 시간을 골라 주세요. / 반납 예정 시간은 지금보다 뒤여야 해요.
- 주행거리를 적어 주세요. / 숫자만 적어 주세요. (예: 42) / 1 이상으로 적어 주세요.

## 빈 상태
무엇이 없는지 말하고, 할 수 있는 다음 행동을 알려 줘요.
| 상황 | 문구 |
|---|---|
| 사용중인 차 없음 | 지금 사용중인 차가 없어요. |
| 등록된 차 없음 | 등록된 차량이 없어요. |
| 검색 결과 없음 | 조건에 맞는 차가 없어요. 검색어나 필터를 바꿔 보세요. |

## 성공 알림 (하단 토스트)
- 빌리기: 「12가3456 아반떼을(를) 빌렸어요.」
- 반납: 「12가3456 아반떼을(를) 반납했어요. (42km)」
