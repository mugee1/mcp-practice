# design MCP 사용법

Claude 에게 우리 팀 **디자인 규칙**(색 · 글자 · 컴포넌트 · 문구)과 **화면 진행 상황**을 물어볼 수 있게 해 주는 도구예요.
규칙(토큰 · 문서)은 읽기만 하고, **화면 상태는 담당자가 말로 바꿀 수 있어요** (바꾸기 전에 Claude 가 확인을 받고, 누가 바꿨는지 기록에 남아요).

📎 **주소:** https://design-mcp-tau.vercel.app/mcp
(브라우저로 열면 이 안내와 같은 페이지가 나와요. 웹사이트가 아니라 Claude 에 등록해서 쓰는 주소예요.)

📊 **디자인 현황판:** https://design-mcp-tau.vercel.app/dashboard — 진행률 · 화면 목록 · 글자색 대비 점검을 한눈에 (자료를 고치면 자동 반영)

---

## 1. 설치 — 한 번만

### Claude Code (터미널)
아무 폴더에서 한 줄. Python 같은 설치는 필요 없어요.
```
claude mcp add --transport http --scope user design https://design-mcp-tau.vercel.app/mcp
```
Claude Code 안에서 `/mcp` → **design · connected** 가 보이면 끝.

### claude.ai (웹 · 데스크톱 앱)
설정 → **커넥터** → **사용자 지정 커넥터 추가** → 이름 `design`, 주소 `https://design-mcp-tau.vercel.app/mcp`

---

## 2. 이렇게 물어보세요
도구 이름을 몰라도 돼요. 평소 말로 물어보면 Claude 가 알아서 골라 써요.

| 알고 싶은 것 | 이렇게 물어보기 |
|---|---|
| 색 · 글자 · 간격 값 | 「경고 색 토큰 알려 줘」 「요약 카드 배경색은?」 |
| 컴포넌트 · 문구 규칙 | 「버튼은 언제 써?」 「반납 지연은 어떻게 보여 줘?」 |
| 글자가 잘 보이는지 | 「positive.primary 글자를 요약 카드 배경에 써도 돼?」 |
| 화면 진행 상황 | 「수정 필요한 화면은?」 「개발에 넘어온 화면은?」 |
| 전체 진행률 | 「디자인 몇 % 됐어?」 |
| 화면 상태 바꾸기 | 「요약 바 수정 끝났어, 완료로 넘겨 줘」 「차량 예약 화면 진행 중으로 바꿔 줘」 |
| 누가 바꿨는지 | 「요약 바 상태 바뀐 기록 보여 줘」 |

## 3. 역할별 예시

| 누가 | 예시 |
|---|---|
| 디자이너 | 「수정 필요한 화면과 이유, 관련 토큰 대비를 보여 줘」 |
| 개발자 | 「개발에 넘어온 화면과 각 화면의 컴포넌트 규칙을 정리해 줘」 |
| PO · 기획 | 「디자인 진행률을 주간 보고 형식으로 정리해 줘」 |
| 리뷰어 | 「이 화면 코드에 토큰에 없는 색이나 대비 부족이 있는지 봐 줘」 |

## 4. 자주 묻는 질문
- **`/mcp` 에서 failed 로 나와요** → 주소 끝이 `/mcp` 인지 확인하고 Claude Code 를 껐다 켜 보세요.
- **자료는 어디서 바꾸나요?** → 화면 상태는 Claude 에게 말로. 토큰 · 문서는 이 폴더의 `design_tokens.csv` · `docs/` 를 고쳐 main 에 올리면 몇 분 안에 모두에게 반영돼요.
- **아무나 써도 되나요?** → 상태를 바꿀 수 있어서 접속 키가 있는 사람만 써요. 주소 뒤에 `?key=키` 를 붙여 등록하세요 (키는 담당자에게 받기).
- **상태 바꾸기가 「꺼져 있어요」 라고 나와요** → 서버에 접속 키 또는 Supabase 설정이 아직 없어요. README 「화면 상태 저장소」 참고.
